Overproduction Factory: a lean game about overproduction

Four processes, one daily order of 480 units. The old rule on the floor is "never let a process stop, build as much as you can." Follow it and every ordered unit ships — yet the day ends in a loss. Players find the crew and work-in-process that actually make a profit.

What participants learn

  • Why building more than the customer needs lowers profit, even when every process looks busy.
  • Takt time: the pace set by customer demand (available time ÷ demand).
  • How to set people per process from work time ÷ takt time.
  • Standard WIP: the minimum stock that keeps the line flowing, and why piles grow when nobody defines it.
  • Why the game, following the Toyota Production System, counts stock with no buyer as worth nothing — and how book profit can hide the problem.

How a session runs

  1. Run the default line. Nobody changes anything. Every order ships, and the profit is negative.
  2. Debrief. The facilitator asks: "Every unit the customer ordered was shipped. So where did the money go?"
  3. Find the takt. Groups set people per process and run the day again.
  4. Standard WIP. Groups compare how many parts to keep between processes.
  5. Back to the workplace. Each person writes one thing to look for tomorrow.

The game never gives the answer first. People have to try, get it wrong, and talk about why — that is where the learning happens.

Questions

Do I need to be a lean expert to run it?

No. The Pro facilitator guide gives you the session plan, the questions to ask at each step and the answers people usually give.

Does it need installation or sign-up?

No. The free version runs in a browser on itch.io. The Pro version is a single file that runs in Chrome, Edge, Safari or Firefox, even without an internet connection.

Is it only for factories?

The setting is a factory line, but the question it raises — is our work matched to what the customer really needs? — is just as useful in offices, hospitals and service work. The facilitator guide ends with questions about your own workplace.

Can I use it in a university class?

Yes. It works well for operations management and lean courses. Contact me if you want to adapt it for a class.
