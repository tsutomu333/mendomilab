Lean simulation games online: free browser games for lean training

These are free, browser-based lean simulation games for training. Each one takes 10–20 minutes to play and 30–90 minutes as a workshop. Nothing to install and no sign-up — open the link, share your screen or put groups in front of a laptop, and run the session. They were built by a consultant with more than 20 years at a Toyota subsidiary consulting company, from the way lean is actually taught on the shop floor.

Overproduction Factory

Four processes and a daily order of 480 units. The old rule on the floor is "never let a process stop, build as much as you can." Follow it and every ordered unit ships — yet the day ends in a loss. Players change the crew and the work-in-process between processes until the line actually makes money. Best for a first lean session, supervisors and improvement teams.

The Supplier's Puzzle

Set in a fictional scenario inspired by Toyota production, the customer needs 8,000 cars this month and players run two suppliers. They change the build order, people and machines and explore how a leveled sequence can lower the supplier's cost. Best for purchasing, planning and supplier development teams, and for teaching heijunka.

How to choose

  • New to lean, or one session only: start with Overproduction Factory. It opens the most basic question — are we building what the customer needs? See overproduction waste examples.
  • Teaching heijunka or working with suppliers: use The Supplier's Puzzle. Read heijunka examples with numbers first if you need a refresher.
  • A half-day workshop: run both. Overproduction first, then the supplier view of the same problem.

How to run a lean simulation session

  1. Run it as it starts. Let groups play without changing anything, so they see the problem with their own eyes.
  2. Ask before you explain. One good question does more than a slide: "Every unit shipped. So where did the money go?"
  3. Let them try and fail. The games never show the answer first. Wrong attempts are where the learning happens.
  4. Compare runs. Write each group's settings and results on a board and compare.
  5. Bring it home. End with one thing each person will look for in their own workplace tomorrow.

Browser games vs. hands-on kits

Classic hands-on simulations — building with blocks or folding paper products on a mini line — are great in a room. Browser games add three things: they run in remote and hybrid classes, they replay a full day or month in minutes so groups can test several ideas, and they show cost and profit numbers that are hard to track by hand. The two work well together.

Questions

Are these lean simulation games free?

Yes. The free versions run in a browser with no sign-up. Pro versions for trainers add customization, a facilitator guide and offline use.

Can I use them in an online or university class?

Yes. They run in a modern web browser, so they work with screen sharing and in classrooms. They fit operations management and lean courses.

Do I need to be a lean expert to run them?

No. The games are designed so the problem shows itself. The Pro facilitator guide gives the session plan, the questions to ask and the answers people usually give.

How long does a session take?

Each game takes 10–20 minutes to play alone, and 30, 60 or 90 minutes as a facilitated workshop.
