製造業の研修に使えるゲーム：トヨタ生産方式を体験する無料の研修ゲーム

製造業の研修で使える トヨタ生産方式（TPS）を体験するゲームです。どれもブラウザで無料で遊べて 登録もいりません。研修なら30〜90分で使えます（時間は下の一覧）。新人研修 監督者研修 改善チームの勉強会 大学の授業に向いています。トヨタの子会社のコンサル会社で20年以上 工場の改善をしてきた人が 現場での教え方をもとに作りました。

研修の目的からえらぶ

  • 新人研修で「ムダ」と「お客様が必要な量」を体で覚えてほしい：造りすぎ工場。「工程は止めるな 造れるだけ造れ」のまま動かすと 注文は全部出せても1日の利益がマイナスになるのを体験します。
  • 監督者や改善チームに 人数と仕掛品の決め方を学んでほしい：造りすぎ工場で タクトタイムと標準手持ちを自分で出します。
  • 購買や生産計画の担当に サプライヤーとの関係を考えてほしい：サプライヤーのパズル。組み立ての順番が サプライヤーの人 設備 在庫のコストにどう影響するかを見ます。
  • まず楽しく入りたい 事務やサービスの人もいる：回らないパスタ屋。飲食店が題材なので だれでも入りやすいです。
  • 半日の研修：パスタ屋 → 造りすぎ工場 → サプライヤーのパズル の順に 身近な題材からつなげます。

ゲーム形式の研修の進め方

  1. まずそのまま動かす：何も変えずに動かして 問題を自分の目で見てもらいます。
  2. 説明の前に問いかける：「注文は全部出せた。ではお金はどこに消えた？」のような問いを1つだけ出します。
  3. 試してまちがえてもらう：答えは先に言いません。まちがえた理由を話し合うところに学びがあります。
  4. 結果をくらべる：グループごとの設定と結果をホワイトボードに書いてくらべます。
  5. 職場に持ち帰る：明日から自分の職場で見るところを 1人1つ書いてもらいます。

人数は何人でもできます。2〜3人で1つの画面を見ながら進めると 話し合いが生まれます。オンラインの研修でも 画面を共有すれば使えます。

講義とゲームはどちらかではなく 組み合わせると効きます。ゲームのあとに考え方を説明すると 言葉が体験とつながります。

無料版とPro版

無料版で遊ぶことも 研修で使うこともできます。造りすぎ工場とサプライヤーのパズルには 研修をする人向けのPro版があり 注文や工数 コストなどを自分の職場に合わせて変えられ 進行役の手引きもつきます（回らないパスタ屋は無料版だけです）。日本語のPro版は準備中です。研修に合わせた作り直しや 進め方の相談は 相談する からどうぞ（最初の1往復は無料）。

よくある質問

無料で研修に使えますか？

使えます。無料版はブラウザでそのまま遊べて 登録もいりません。研修をする人向けのPro版は 設定を自分の職場に合わせて変えられ 進行役の手引きがつきます（日本語版は準備中）。

リーンやトヨタ生産方式にくわしくなくても進行できますか？

はじめてでも このページの手順で進められます。まずそのまま動かして 結果を見てから 何が起きたかを問いかけてください。

オンライン研修でも使えますか？

使えます。ブラウザで動くので 画面を共有すれば オンラインでも教室でも使えます。

新人研修に向いているのはどれですか？

造りすぎ工場です。必要な量を超えて造ると 在庫やコストがどう増えるのかを 短い時間で体験できます。
