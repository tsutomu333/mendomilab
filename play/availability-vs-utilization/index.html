    Notes (contains hints)
    • One number hides the difference: if you track machine time with a single number, a breakdown and a planned stop both look like "not running." Toyota separates them: availability asks whether the machine could run when it was needed, and utilization asks how much the machine was used against the order.
    • Availability 可動率 · bekidō-ritsu: the share of the time the machine was needed that it actually ran. It only looks at red. Red is abnormal, so the target is 100%.
    • Utilization 稼働率 · kasedō-ritsu: how much the machine was used against its capacity. The order decides it, so a low number can be fine. When the order exactly matches capacity, 100% is not overproduction. What matters is building to the order, not pushing utilization up.
    • What red costs: with red, you need extra machines to win back the lost time. Red shows up as money spent on too many machines.
    • What yellow costs: yellow is time spent not making what nobody ordered. Filling it creates parts you cannot sell (overproduction). When there is a lot of yellow, ask a separate question: do we own more machines than the orders need? Depreciation is paid even when a machine is idle.
    • Why the readings differ: in Japanese both words can be read "kadō-ritsu." At Toyota, 可動率 is read "bekidō-ritsu" and 稼働率 "kasedō-ritsu," so people can tell them apart by ear.
    • Colors: this is how the game shows it — green = running, yellow = stopped because the order is done, red = down because of a breakdown. Real signal tower colors are set by each plant and machine.
    • Check the denominator: "utilization" and "availability" are defined differently from company to company, and OEE uses "availability" for something close to bekidō-ritsu. If breakdown time is taken out of the denominator, breakdowns stop lowering the number. This game uses the TPS definitions. More on this
    Formulas
    • Availability = running time (green) ÷ (running time (green) + down time (red))
    • Utilization = running time (green) ÷ (machines × 8 hours)
    • Sales = parts delivered against the order × $1.00 (extra parts cannot be sold)
    • Materials = parts made × $0.40
    • Depreciation = machines × $100 (the same whether a machine runs or not)
    • Shortage cost = parts short × $2.00 (rush shipping and customer handling; a game assumption, not a Toyota figure)
    • Profit = sales − materials − depreciation − shortage cost
    • Grade S: same profit as the best number of machines for this order / A: 90% of it or more / B: any profit / C: a loss
